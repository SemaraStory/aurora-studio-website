04 — FAQ

Pertanyaan yang sering ditanyakan

Berapa lama waktu pengerjaan project? +

Rata-rata project website memakan waktu 4-8 minggu, tergantung kompleksitas. Kami akan memberikan timeline jelas setelah diskusi kebutuhan di awal.

Apakah bisa untuk project skala kecil? +

Tentu! Kami menerima project dari landing page single-page hingga platform enterprise. Setiap project mendapat perhatian yang sama.

Bagaimana sistem pembayarannya? +

Kami menggunakan sistem milestone: 30% DP, 40% setelah desain disetujui, 30% saat peluncuran. Semua tercatat jelas di kontrak.

Apakah ada support setelah website live? +

Ya, kami menyediakan maintenance 3 bulan gratis. Setelah itu ada paket maintenance bulanan sesuai kebutuhan klien.

Bisakah saya melihat progress selama pengerjaan? +

Tentu. Kami menggunakan tool kolaborasi seperti Figma dan Notion, serta weekly meeting rutin agar klien selalu update.

Mari wujudkan ide brilian Anda.

Ceritakan project Anda. Kami akan merespons dalam 24 jam.
